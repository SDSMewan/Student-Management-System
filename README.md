<h1>Student Management System</h1>

<p>It has been a great pleasure for me to work on this exciting and challenging project. This
project proved good for me as it provided practical knowledge of not only programming
in Python based applications.</p>
<p>It also provides knowledge about the latest technology used in development.e. This will
provide better opportunities and guidance in future in developing projects independently.</p>

<h2>Objective</h2>
<p>This mini project aims to evaluate your understanding of:</p>

<ul>
  <li>Basic Python programming</li>
  <li>Control structures (if, loops)</li>
  <li>Data structures (lists, tuples, sets, dictionaries)</li>
  <li>File handling</li>
  <li>GUI development using Tkinter</li>
</ul>

<h2>Technical Requirements</h2>
<h3>Tkinter GUI Components </h3>

<ul>
  <li>Main window</li>
  <li>Labels</li>
  <li>Entry fields</li>
  <li>Buttons</li>
  <li>Frames</li>
  <li>Listbox or Treeview</li>
  <li>Message boxes</li>
  <li>Proper layout management</li>
</ul>

<h3>Python Programming Concepts</h3>

<h4>Basic Python</h4>
<ul>
  <li>Variables</li>
  <li>Functions (at least 5 user-defined functions)</li>
  <li>Proper modular structure</li>
</ul>

<h4>Control Structures </h4>
<ol>
  <li>if–else conditions</li>
  <li>for or while loops</li>
  <li>Input validation</li>
</ol>

<h4>Data Structures </h4>
<p>You must use:</p>
<ul>
  <li>List → Store multiple records</li>
  <li>Dictionary → Store structured data</li>
  <li>Tuple → Store fixed information </li>
  <li> Set → Prevent duplicate entries</li>
</ul>
<p>Explain in comments where and why each structure is used</p>

<h3>File Handling </h3>
<p>Your system must:</p>
<ul>
  <li>Save data to a file </li>
  <li>Read data from file when program starts</li>
  <li>Update file when data changes</li>
  <li>Handle file errors properly</li>
</ul>
